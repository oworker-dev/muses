# Muses MVP Delivery

> Archived route: this file records the PPT-first estimate approved in an
> earlier planning round. APCC decision `agent-first` supersedes its component
> sequence and fixed 25-37 day budget. The current route is
> `docs/internal/Agent优先创作与工作流模型.md`: use the verified image foundation,
> deliver Agent Core and its reliability/orchestration gates, then enter PPT.
> The value guardrails below remain historical input, not the active queue.

## Current Handoff

1. Freeze the Agent-first product, workflow-call, node-registry, and runtime contracts.
2. Deliver the server-authoritative Operation Gateway and independent Agent Core.
3. Pass the single-Agent creative-canvas and reliability gates, then minimum orchestration.
4. Keep first-image human acceptance parallel; enter PPT only after the Agent gates.

## Historical Outcome

Deliver the first usable general capability modules through a real PPT/commercial-material production loop instead of completing every platform layer before scenario validation.

## Historical Critical Path

1. Gate 0: obtain one privacy-safe real PPT acceptance sample, spike editable PPTX and page-canvas routes, then freeze only the minimum contracts.
2. Slice 1: deliver CreativeDocument, Command, Revision, persistence, recovery, and the minimum page canvas.
3. Slice 2: deliver Asset, Provenance, Job, Capability, and one replaceable image capability.
4. Slice 3: deliver a controlled Agent, a code-defined fixed PPT recipe, and editable PPTX export.
5. MVP Gate: use the system for one real comparative delivery and one external-user observation.

The planning budget is 25–37 focused engineering days. Gate timeboxes trigger scope reduction, not automatic extension.

## Historical Release Gate

- The selected real PPT task completes from Brief to editable PPTX and structured Muses export.
- Confirmed document changes survive refresh and explicit failure cases.
- UI, Agent, and the fixed recipe reuse common Command, Capability, Job, Asset, and Provenance semantics.
- Each claimed reusable module has an independent Harness, a real adapter where applicable, contract tests, known limitations, and scenario evidence.
- The real delivery improves at least one measured value dimension without regressing editability, user freedom, reliability, privacy, or security.

## Historical Scope Boundary

The first MVP excludes realtime collaboration, a general workflow editor, video/audio/music timelines, complete PPTX round-trip fidelity, plugin markets, mobile/desktop clients, and autonomous end-to-end Agents. The full route and cut order live in `docs/internal/MVP交付路线.md`.

## Historical Human Input

The product owner supplies one privacy-safe PPT task package containing the Brief, allowed input materials, current output or target sample, current process, known time/cost/rework data, acceptance criteria, editable-output requirements, and privacy restrictions. Unknown measurements remain unknown.
