# AI 音频与音乐模块

## 1. 模块使命

让用户和 Agent 在同一项目上下文中完成从声音意图到可编辑、可追溯、可授权交付的音乐、对白、配音、音效和混音，消除 AI 短剧、短视频、广告与演示在视觉完成后仍需跨平台搬运声音素材的断点。

它是专业媒体能力模块，不是视频对象中的附属 URL，也不是模型供应商的薄封装。

## 2. 用户任务

- 根据故事、品牌、画面情绪、节奏和时长生成或检索合适音乐。
- 为角色与旁白生成、录制、编辑和多语言适配语音。
- 生成环境声、拟音、转场和强调音效。
- 将音乐、对白、音效和视频镜头按时间对齐并完成基础混音。
- 对已有音频进行分轨、人声分离、降噪、裁剪、变速、响度和母带处理。
- 生成续写、变奏、短版、循环版和不同渠道版本，同时保持主题一致。
- 确认素材、声音身份、模型与商用许可，安全导出和发布。

## 3. 核心对象

模块基于共享 `Artifact` 与 `Asset`，新增媒体扩展而非复制资产系统：

- `AudioArtifact`：具有创作语义的音频成果或引用。
- `AudioSource`：录音、上传、生成、合成、分轨或派生来源。
- `AudioTrack`：时间轴中的音乐、对白、音效、环境声或总线轨道。
- `AudioClip`：轨道上的时间片段，引用 Asset 并包含入点、出点、增益、淡化和变速。
- `MusicStructure`：节拍、速度、调性、段落、小节、情绪与可循环区间等可选分析。
- `VoiceIdentity`：经授权的说话人或合成音色引用，不保存绕过授权所需的原始敏感信息。
- `MixRevision`：轨道、自动化、效果链和导出设置的已确认修订。
- `AudioLicenseRecord`：输入与输出的许可来源、用途、地域、期限、归属和限制。

所有对象显式关联 `workspaceId`、Schema 版本、Provenance 和权限；大型波形、代理文件、分轨和最终渲染由 Asset 管理。

## 4. Capability Families

- `audio.generate.music`：文生音乐、参考音乐生成与受控变化。
- `audio.extend.music`：续写、循环、段落扩展和结构变体。
- `audio.synthesize.voice`：经授权的文本转语音和多语言配音。
- `audio.generate.sound-effect`：音效、环境声与拟音生成。
- `audio.separate.stems`：人声、伴奏或多分轨分离。
- `audio.clean`：降噪、去混响、修复和人声增强。
- `audio.analyze`：转写、说话人、节拍、调性、段落、响度和情绪分析。
- `audio.transform`：裁剪、拼接、变速、变调、格式和声道转换。
- `audio.mix`：轨道混合、响度标准化和基础母带。
- `audio.sync.visual`：依据镜头、节奏点和时长提出同步或剪辑建议。

具体能力名称和 Schema 在 Wave 0/后续媒体计划中版本化，本页只定义长期家族与职责。供应商响应不得直接成为 Capability 输出契约。

## 5. 时间与编辑语义

音频共享 CreativeDocument 的稳定 ID、Command、Revision、Asset 和选择协议，但拥有专业时间语义：

- 内部时间基准必须明确，支持采样时间与展示时间之间无歧义转换。
- 非破坏编辑优先；裁剪、增益、淡化、效果和排列保存为编辑参数，渲染产生派生 Asset。
- 波形和代理文件是可重建缓存，不是权威编辑状态。
- 音频时间轴可与视频时间轴共享主时钟和标记，但不强迫二维画布承载采样级编辑。
- 播放预览与最终渲染允许不同质量路径，但必须可解释差异。
- 撤销轨道操作使用 Command；已产生的外部生成费用或发布副作用使用补偿而非伪装撤销。

## 6. 与其他内核连接

- **Agent**：读取故事、镜头、品牌和选择上下文，提出声音计划，通过 Capability 生成/分析，通过 Command 放置和修改 Clip。
- **Workflow**：以类型化节点完成脚本转写、角色配音、分镜配乐、响度处理、版本批量和人工审批。
- **视频**：共享主时间轴、镜头标记、代理文件与最终合成清单。
- **品牌**：引用批准的声音 Logo、主题音乐、音色、语速、禁用风格和许可规则。
- **发布**：针对渠道检查时长、采样率、声道、响度、版权和声音授权。
- **Job**：生成、分轨、转写、混音和渲染全部采用可取消、可重试、幂等提交的长任务语义。

## 7. 权利、安全与来源

- 每项生成或派生内容保留输入、父 Asset、模型、版本、参数、时间、操作者、成本和供应商条款。
- 声音克隆或身份化语音必须有可验证授权、允许用途和撤销/到期状态；高风险用途需要显式确认。
- 发布前检查音乐、样本、录音、声音身份和模型输出许可，未知许可不得默认为可商用。
- 提示与元数据不得泄漏受保护音乐、客户身份或未发布内容。
- 模块提供相似性和内容安全适配点，但不把自动检测结果当作最终法律结论。
- Build in Public 只公开模块代码、Schema、评测和匿名结论，不公开用户声音、客户音频或授权材料。

## 8. 独立与组合验收

### Gate A

通过 Playground 输入文本/参考和时长，运行模拟能力，得到可预览 Audio Asset、Job 进度、Provenance 与许可状态；支持失败、取消、重试和格式验证。

### Gate B

至少两个调用方使用相同 Capability Manifest；模拟供应商和真实供应商适配器通过同一契约测试，替换供应商不改变 AudioArtifact 语义。

### Gate C

同一能力分别由时间轴 UI、Agent Tool 和 Workflow Node 调用，结果进入同一资产与命令体系并可在视频或演示中引用。

### Gate V

在真实 AI 短剧或短视频项目中，预先测量工具切换、素材搬运、声音对齐返工、许可不确定性和成片周期；只有能力改善主要指标且不突破质量、成本、授权与自由护栏，才进入稳定模块。

## 9. 非目标

- 当前不自研基础音乐或语音模型。
- 当前不复刻完整专业 DAW、乐谱软件或录音棚硬件控制。
- 不承诺自动解决所有音乐版权与司法辖区问题。
- 不把未经授权模仿具体艺术家、公众人物或个人声音作为产品卖点。
- 不为了统一模型牺牲视频、音乐、对白和音效各自的专业编辑语义。
