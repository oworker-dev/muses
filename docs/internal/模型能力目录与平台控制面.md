# 模型能力目录与平台控制面

## 1. 产品定位

Muses 需要 AI 应用与工作流平台中服务于创作的基础设施能力，但不是通用 AI 应用开发平台。类型化变量、耐久执行、模型调用、并行、容错、观测和版本化属于平台内核；用户可见节点仍以图像、视频、音乐、演示、品牌、审核、编辑、Agent 和交付等创作任务为边界。

Coze、Dify 等平台可以作为变量绑定、DAG、节点配置和运行调试的体验参考，不能反向决定 Muses 的产品分类。HTTP、数据库 CRUD、任意代码、通用插件和应用发布节点不因“技术上通用”自动进入产品。

## 2. 为什么需要独立控制面

模型规格不能散落在 Studio 组件、节点类型或供应商适配器中。LLM、图像、视频、语音、音乐和未来模型都需要统一回答：

- 当前有哪些可用模型和版本。
- 模型支持哪些输入、输出、参数、尺寸、时长和格式。
- 哪些工作区可以使用，预算和并发限制是什么。
- 请求由哪个供应商连接执行，失败时是否允许路由到替代供应。
- 运行前预计消耗多少积分，运行后实际用量和费用如何结算。
- 规格、价格或供应发生变化时，旧工作流如何继续重放和迁移。

Muses 复用 OWorker Site Admin 的身份、权限、审计和界面壳，增加独立的“Muses Platform”导航分组。站点用户、收入、健康与审计属于站点运营；模型、能力、价格、路由和用量属于产品控制面。两者共享平台基础，但不能混成一个含义模糊的后台模块。

## 3. 控制面对象

```text
Provider
  -> ProviderConnection
  -> ModelOffering
  -> CapabilityProfile
  -> PriceBookEntry
  -> RoutingPolicy
  -> UsageRecord
```

### `Provider`

供应商的稳定身份与政策元数据。凭证不属于 Provider 公开记录。

### `ProviderConnection`

服务端连接、地区、Base URL、密钥引用和健康状态。数据库只保存密钥引用或加密载荷，不把明文凭证返回浏览器、写入工作流或运行事件。

同一 Provider 下可以存在多个连接，而且每个连接必须显式声明可用能力族与模型范围。不能假设一个 API Key 同时拥有 LLM、图像、视频、语音或音乐权限；现实供应中，同一账号的不同 Key、不同网关或不同项目经常只开放其中一部分。`ModelOffering.enabled = true` 只表示平台允许发布该供应，不等于任意连接当前可调用。运行路由必须同时满足 Offering 已发布、连接能力匹配、凭证可解析和健康状态可接受。

Alpha 阶段允许用环境变量引导媒体连接：图像可独立使用 `OPENAI_IMAGE_API_KEY`/`OPENAI_IMAGE_BASE_URL`，未配置独立图像连接时才兼容回退到 `OPENAI_API_KEY`/`OPENAI_BASE_URL`。显式图像 Base URL 必须配显式图像 Key，禁止把共享 Key 自动转发到另一个 endpoint。独立 `muses-agent` 当前从自身部署环境读取文本模型凭证；由 Muses 管理员 Provider 控制面向 Agent Host 安全下发版本化路由仍是未完成的生产 Gate，不能写成已经接通。环境变量层不是长期管理界面，也不能反向成为领域模型。

### `ModelOffering`

一个可以被工作流精确引用的模型供应版本。`modelRef` 必须包含稳定供应身份和不可变规格版本，例如 `openai/gpt-image-2@2026-07-28`。显示名、启停和工作区可见性可以变化；已经发布的能力规格不得原地改变。

### `CapabilityProfile`

声明模型支持的媒体类型、操作模式、输入端口、输出基数、参数 Schema 和约束。例如图像模型声明文生图/图生图、参考图数量、比例、分辨率预设、自定义尺寸范围、宽高倍数和合法化策略。供应商私有字段由 Adapter 映射，不进入通用节点契约。

### `PriceBookEntry`

版本化价格条目，包含计价单位、积分单价、币种参考、有效期和估算规则。规格版本与价格版本分开；价格变化创建新条目，历史 Run 永远保留当时的估算和结算快照。

### `RoutingPolicy`

按工作区、地区、数据策略、预算、质量、可用性和灰度状态选择具体供应。首图阶段只启用一个明确适配器，不提前实现复杂自动路由，但契约不得把供应商写死进节点。

### `UsageRecord`

把 WorkflowRun、Job、节点、模型供应、供应商请求、Token/媒体计量、价格版本、预计费用和实际费用关联起来。它是面向计量与审计的事实，不替代 Workflow SDK 的 Run/Step/Event。

Workflow SDK 的 World 已提供追加式 Event 以及 Run、Step、Hook 的物化视图，可直接查询状态、attempt、开始/结束时间、错误和序列化 I/O；展示 I/O 时使用官方 `hydrateResourceIO()`，不另造一套底层调用链存储。SDK 原生在 workflow/Step 队列消息间传播 OpenTelemetry context 并产生运行 span；Muses 复用该上下文接入后续遥测后端，不向产品 DSL 填入 trace id，也不自建第二套 span 表。SDK 不理解 Token、图片张数、媒体时长、供应商账单或 Muses 积分，因此这些业务计量必须由 `UsageRecord`、PriceBook 快照和积分账本补充，并以 run/node/provider request id 与 SDK 观测事实关联。

面向 Studio 的 `observability 0.1.0` 是上述事实的安全读取投影：World 提供 Run/Step 时序与水合输入，Muses 事件提供业务节点、输出、错误和 AI SDK usage，reservation 提供公开模型/Profile/PriceBook 与积分事实。它不拥有新数据，不返回供应商执行模型 ID、连接凭证、完整 Definition、`creditContext`、对象字节、存储键、原始堆栈或 OpenTelemetry carrier。Token 字段只在供应商实际返回时出现；缺失状态必须显示为“供应商未返回”，不能记为零。World 暂时不可读时降级为事件摘要，不能影响 Run 的所有权和存在性判断。

## 4. 图像规格表示

图像节点保存稳定用户意图，而不是供应商请求参数：

```ts
type ImageGenerationIntent = {
  modelRef: string;
  inputs: {
    prompt: { mode: "variable" } | { mode: "fixed"; value: string };
    referenceImages:
      | { mode: "variable" }
      | { mode: "fixed"; assetIds: string[] };
  };
  output: {
    size:
      | { mode: "preset"; presetId: string; aspectRatio: string }
      | { mode: "custom"; width: number; height: number };
    count: number;
  };
  quality: string;
};
```

变量引用由类型化数据边表达，固定值只属于当前节点；切换为固定值后，原 prompt 数据边转为控制依赖以保留执行顺序，不允许反向改写上游。固定参考图只保存工作区内已确认的 Asset ID，不保存临时上传 URL、字节或对象键。

Profile 将输出意图解析为合法请求。GPT Image 2 的宽高 16 倍数、最长边 3840、像素范围和最大 3:1 比例属于其 `2026-07-28.1` Profile/Adapter；运行前同时显示用户请求像素和实际供应商像素。`1K/2K/4K` 是便捷意图，不跨模型假定同一原生实现。GPT Image 1.5 当前只开放供应商真实支持的三个离散尺寸；模型不原生支持的档位必须禁用，或明确展示额外放大步骤和费用，不能静默伪装成原生输出。

## 5. 管理权限与发布生命周期

- 平台管理员管理供应商、模型供应、能力规格、价格、全局启停和灰度。
- 工作区管理员选择允许使用的模型、预算、默认策略和未来的 BYOK 连接。
- 创作者只看到当前工作区可用且已发布的能力，不看到密钥、内部连接或未发布草稿。
- 规格使用 `draft -> published -> deprecated -> retired` 生命周期；已被发布工作流引用的版本不能物理删除。
- 任何新增或修改都写入审计日志；高影响启停、价格和路由变更保留操作者、差异和生效时间。

管理员后台已经提供 Provider Connection 与 Credential Vault：管理员创建或轮换密钥时，浏览器只提交到服务端密钥管理边界；本地可自托管适配器使用 `MUSES_CREDENTIAL_MASTER_KEY` 进行 AES-256-GCM 认证加密，数据库保存密文版本、Key ID、末尾脱敏标识、能力范围和审计事实，任何读取投影都不返回明文或密文。该 Adapter 是可替换边界，托管部署后续可接 KMS/HSM；主密钥轮换必须先重加密现有版本，不能直接替换环境变量导致历史连接不可解密。

同一 Provider 可以建立多个只授权 LLM、图像、视频、语音/音频或音乐的连接，并通过模型白名单和 Offering 显式绑定收窄路由。健康检查按能力执行非生成式模型元数据请求，记录最近成功、确定性拒绝、限流和暂时不可用状态；它验证连接与模型可见性，不声称验证生成质量。新建付费图像 Run 会在启动 Workflow SDK 前选择连接，只把 `providerConnectionId` 冻结到服务端执行快照；Step 调用时解析该精确连接。已冻结连接丢失、停用、健康不可用或无法解密时必须失败，不能回退到另一把密钥。自动故障转移只有在供应商请求明确未执行或具备跨供应幂等保证时才允许，不能用重试掩盖可能重复计费的图像、视频或音乐调用。

## 6. Studio 消费规则

Studio 通过只读目录接口取得已发布模型供应，并按 Capability Profile 渲染参数控件。节点只保存 `modelRef`、通用输入来源、输出意图和已声明参数；不得保存 API Key、Base URL、供应商 SDK 对象或可变价格。

发布和运行时在服务端重新校验模型状态、工作区授权、参数约束和积分余额。浏览器校验只改善体验，不能成为安全边界。

## 7. 当前首个切片

Gate 1.1 首先交付：

1. 两个 GPT Image 供应版本的数据库种子、图像 Capability Profile 和积分价格条目。
2. Site Admin 中模型目录、规格、价格和启停入口。
3. Studio 的只读活动目录接口和模型驱动配置。
4. 一个 OpenAI Images Adapter，支持文生图、以 Asset ID 引用的图生图、模型合法尺寸解析和用量回传。
5. 运行记录对 `modelRef`、规格版本、价格版本、预计/实际积分和 AI SDK usage 的快照。

LLM、视频和音乐沿用同一对象边界，但只有进入真实用户任务后才添加供应与编辑表单；本切片不为后台“看起来完整”填充虚假模型。

当前 Site Admin 已能创建、停启和轮换 Provider Connection，按能力与 Offering 绑定，并执行无生成费用的在线健康检查。数据库连接优先于环境变量；没有选择数据库连接时，环境变量仍作为部署引导与兼容回退。当前本地 Vault 使用单一活动主密钥，尚未交付 KMS/HSM Adapter、主密钥在线重加密、工作区 BYOK、跨地区数据策略和安全自动故障转移，因此不能把整个生产控制面宣称为最终完成。

### 7.1 已落地证据

- `0003_muses_model_catalog.sql` 建立 `model_provider`、`model_offering`、`capability_profile` 和 `price_book_entry`，并种下两个 GPT Image 供应版本；`0004` 纠正价格生效窗口；`0005_image_input_resolution_contract.sql` 新增参考图资产记录、退役旧 Profile 并发布 `2026-07-28.1` 规格。数据库触发器防止已发布身份、规格和价格原地改写或物理删除。
- `/api/studio/model-catalog` 只向经过工作区授权的 Studio 返回已启用发布版本，并且不返回供应商执行模型 ID 或凭证。
- Studio 图像节点与 `WorkflowDefinition 0.3.0-draft` 保存稳定 `modelRef`、单向输入来源和输出意图；模型、比例、分辨率、数量、质量和估价 UI 由 Profile/PriceBook 投影。
- 参考图采用“预签名 PUT → 服务端读取并用 Sharp 校验 → ready Asset ID”的流程；内容校验失败才进入 `rejected`，瞬时对象存储故障保留 `uploading` 并允许重试。
- 运行提交会在调用 Workflow SDK 前重新解析并校验 Offering/Profile/PriceBook、参考图所有权和实际尺寸，将 `modelRef`、Profile 版本、PriceBook 版本、积分单价、供应商执行 ID、参考 Asset ID 和实际供应商尺寸冻结到 reservation 快照。Workflow Step 只使用这份冻结快照。
- `GET /api/studio/workflow-runs` 已组合 Workflow SDK World、Muses 节点事件、AI SDK usage 和 reservation 快照，向用户展示实际输入/输出、Run/节点耗时、公开模型与规格版本、请求/合法尺寸、图片/Token 用量和预计/实际积分；默认界面不再展示 Harness/SDK 技术说明，attempt 只保留为次级诊断。
- `/admin/models` 显示目录、规格、价格和可用状态，平台管理员可审计地启停 Offering。规格或价格变更必须由后续新建版本，不提供就地编辑已发布记录。
- `0017_provider_connection_credential_vault.sql` 建立多连接、版本化加密凭证、Offering 绑定和按能力健康状态；数据库触发器阻止跨 Provider 或能力错误绑定，并保证每个连接最多一个活动凭证版本。
- `/admin/providers` 提供连接创建、能力声明、模型白名单、Offering 绑定、停启、凭证轮换和健康检查。所有操作复用 Site Admin 授权与 `audit_log`，UI 和服务端投影只显示凭证末四位。
- 图像提交将选中的连接 ID 与 Model/Profile/PriceBook 一起冻结到服务端计费上下文；Workflow Step 解析精确连接。Agent LLM 调用也使用同一能力路由；无数据库连接时才使用 LLM/图像各自的环境变量。
- `verify:provider-connections` 使用本地假密钥验证密文落库、显式路由、运行时解密、原子轮换和 Admin 脱敏投影，并在结束后清理精确测试记录。
