# 价值假设与证据台账

## 使用规则

这是活文档，不是愿景宣传。每项重要开发必须关联至少一个假设 ID；实验完成后更新证据、结论和日期。包含客户隐私的原始材料保存在受控位置，本页只写可公开摘要。

证据等级采用[产品价值宪法](../shared/价值宪法.md)定义的 1–7 级。`unknown` 表示尚未测量，不得写成零。未经验证的数字是目标或阈值，不是事实。

| ID | 假设 | 当前证据 | 下一验证 | 继续条件 | 停止/转向条件 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| V-001 | AI 短剧创作者最痛的问题之一是脚本、图片、视频、配音、音乐与剪辑之间的上下文和文件搬运 | 创始人重复经历，等级 4，待量化 | 记录至少 3 个真实项目的工具链、搬运次数、耗时与返工 | 问题在多数项目重复出现且明显影响交付 | 问题低频，或现有自动化已足够 | 待采集基线 |
| V-002 | PPT 定制最需要的是研究、结构、文案与视觉在可编辑交付中的连续闭环，而非单次整份生成 | 创始人重复经历，等级 4，待量化 | 记录至少 3 个真实订单的审稿轮次、局部修改与不可编辑返工 | 连续上下文和局部编辑显著降低交付时间 | 客户主要接受扁平成品且无需持续编辑 | 待采集基线 |
| V-003 | 用户会因为“Agent 速度 + 专业控制 + 可回滚”而优先选择本平台 | 观点与自身需求，等级 1–2 | 可点击原型与人工 Wizard-of-Oz 任务对比 | 目标用户更快完成任务且主动选择该模式 | 用户更偏好单点生成或传统手工流程 | 待验证 |
| V-004 | 完全开源、自托管和结构化导出会提高信任与采用，而非只吸引免费用户 | 价值判断，等级 1 | 访谈、落地页选择实验、自托管意愿与付费托管意愿 | 自由度提高采用/推荐且托管仍有付费意愿 | 目标用户不关心自由且维护成本不可持续 | 待验证 |
| V-005 | 音频与音乐纳入同一项目上下文会明显改善 AI 短剧与短视频交付 | 创始需求，等级 2–4 | 测量外部音频工具切换、对齐返工、许可记录和成片时间 | 统一时间轴/来源减少工具切换和返工 | 音频生产天然独立，连接价值很低 | 待采集基线 |
| V-006 | 同一创作内核可以同时服务 AI 短剧和 PPT，而不牺牲专业体验 | 架构假设，等级 1 | 分别完成一条真实端到端链路并比较共享对象/协议 | 共享 Asset、Job、Command、Provenance，专业编辑语义保持独立 | 为共享而产生大量条件分支或体验退化 | 待验证 |
| V-007 | 官方托管的省心、算力、协作与可靠性足以支撑开源产品商业化 | 行业类比，等级 1–2 | 付费意愿访谈、预售/试点、托管成本模型 | 成功任务毛利与留存支持持续运营 | 价格无法覆盖成功交付成本或用户只愿自托管 | 待验证 |

## 创始人业务基线模板

每个真实项目至少记录：

| 字段 | 说明 |
| --- | --- |
| 项目类型 | AI 短剧、PPT 定制或其他 |
| 目标结果 | 客户/受众最终使用什么成果 |
| 工具链 | 使用的工具、模型和人工服务 |
| 流程步骤 | 从需求到交付的实际步骤，不写理想流程 |
| 总周期 | 起始、首稿、最终交付时间 |
| 主动工时 | 人工实际投入时间 |
| 外部成本 | 模型、软件、素材、算力与外包成本 |
| 工具切换/搬运 | 平台切换、上传下载、格式转换次数 |
| 生成与采用 | 生成数量、保留数量、最终采用数量 |
| 修改与返工 | 轮次、原因、是否可以局部修改 |
| 一致性缺陷 | 角色、品牌、视觉、声音、叙事问题 |
| 自由度阻塞 | 模型限制、导出限制、格式锁定、价格或审查问题 |
| 客户结果 | 是否按期、是否验收、是否复购/推荐 |
| 隐私级别 | 可公开摘要、仅内部、客户机密 |
