# 图片转可编辑方案评审清单

## 当前状态

- [x] APCC 架构决策 `ai-3` 已批准
- [x] 产品负责人已确认技术方案并要求推进首个测试图
- [x] Fixture-driven SVG 垂直切片已交付
- [x] Provider Spike v2 与本地回归测试已实现
- [ ] 新版真实 VLM/Image Edit 首个固定样本证据已通过（v2 为失败回归样本）
- [ ] API、Worker 持久执行、SDK Client 和 UI 尚未开始

## 边界

- [ ] 能力保持宿主无关，不导入 Muses 领域包或数据库
- [ ] Muses 只依赖公共 Media Client 和版本化契约
- [ ] Media Service 不拥有 Workspace、积分或 DesignDocument 权威状态
- [ ] 不为每个图像原子能力拆微服务
- [ ] SDK 不包含服务端实现、Provider SDK 或密钥

## 契约

- [ ] 请求、结果、状态机、错误码和幂等语义已经版本化
- [ ] BBOX 格式、坐标原点和变换语义无歧义
- [ ] Manifest 能映射到 SVG、DesignDocument 和其他宿主
- [ ] `partial`、低置信度和关键内容改变不会静默成功
- [ ] Usage Receipt 足以支持宿主结算

## 流水线

- [x] 文字本地去除、按层级非文字隔离、透明重绘、可编辑底图修复顺序已确认
- [x] 当前 Provider 路径不上传 Mask，只使用普通 Image Edit 和强化提示词
- [x] diffuse `background-field` 不参与前景重绘，作为修复后的可编辑背景资产交付
- [x] 清晰边界 `bounded-artwork` 不得被吞入底图，必须作为独立可替换 raster
- [x] 父层资产在输入和输出阶段均扣除后代区域
- [x] 默认元素重绘输入不混入原图背景上下文
- [x] 按空间/语义小批次使用局部稀疏画布，并记录全局 origin
- [x] Alpha 与 chroma key 路径均有明确后处理和泄漏检测
- [x] 自动探测负责裁切，原始逻辑坐标负责最终放置，比例漂移不强行拉伸
- [x] 模型失败结果不直接发布；`source-preserving-fallback` 仅作为显式视觉保真降级
- [x] 根节点不会因共同的 `parentId=null` 被错误合并到同一重绘批次

## 验证

- [ ] 已确定真实评测图片及合法使用范围
- [ ] 已定义关键内容绝对失败规则
- [ ] 已定义 OCR、元素、坐标、Alpha、底图、QA、延迟和成本指标
- [ ] 已定义取消、重试、崩溃恢复和重复收费验证
- [ ] Provider 路由替换必须运行同一固定评测集
- [x] 首个样本已记录 VLM、前景 Edit、底图 Repair 的真实 request ID 与耗时
- [ ] 首个样本达到逐元素透明、截断、比例和关键区域 QA 门槛（v3 仍有 75 个保真兜底）
- [x] 保真兜底覆盖文字时，QA 会显式报告 `editableTextVisible=false`，不伪装为完整可编辑

## 开发放行

`ai-3` 已批准，确定性 Fixture Gate 已放行并完成。Provider Spike 当前因视觉质量
失败而重新进行中；必须先通过 analysis-only 场景审核和逐元素 QA，再推进新的真实
Image Edit。Media API/Worker、SDK Client 和 Studio 集成仍需各自的 APCC 任务与对应
验证，不因单个测试图的全局相似度而自动放行。
