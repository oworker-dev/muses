# Docs

Muses project documentation lives here.

Start with:

- `shared/概览.md` for the product definition.
- `shared/目标.md` for the long-lived end goal.
- `shared/价值宪法.md` for user experience, value, metrics, and stopping rules.
- `shared/开放原则.md` for open source, Build in Public, privacy, and user freedom.
- `internal/长期架构.md` for durable architecture boundaries.
- `internal/内核验收路线.md` for reusable-kernel acceptance.
- `internal/价值假设与证据台账.md` for falsifiable assumptions and evidence.

Existing runtime and operational references remain available in this directory and under `ops/`, `integration/`, `interfaces/`, and `delivery/`. Structured goal, plan, task, decision, owner, and version state lives under `.apcc/` and is inspected with `apcc status`.
