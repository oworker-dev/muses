# 首个公开源码版本

Muses 的首个公开源码快照建立 Build in Public 的可验证起点，而不是宣称产品功能已经完成。

## 包含内容

- 可运行的 OWorker SaaS 基础：认证、账户、计费、存储、队列、管理、审计、API、Worker 与本地 Docker 环境。
- APCC 管理的项目终局、计划、任务、重要决策与版本记录。
- 产品价值宪法、开放原则、长期架构、内核验收路线和价值证据台账。
- AI 图像、视频、音频/音乐、演示、Agent、工作流和开放生态的长期模块边界。

## 当前阶段

当前是 Value Foundation。下一步是采集 AI 短剧和 PPT 定制真实工作流基线、验证外部用户需求，然后通过 Technical Discovery 验证会影响 Wave 0 契约的关键技术路线。

## 验证

- `pnpm run check`
- `apcc doctor check`
- `apcc site build`
- 暂存文件路径与凭证模式扫描

## 已知限制

- 正式 AI 创作内核尚未实现。
- 当前 Web UI 仍是中性 SaaS Starter，而不是最终 Muses 创作体验。
- 生产部署、托管服务和公开路线仍在建设。
- 尚未选择和写入正式 `LICENSE`；当前是公开源码预览，不是已经授予复用权利的开源发行版。

## 安全与隐私

仓库不包含本地 `.tmp/` 凭证、用户项目、客户材料或私有遥测。发现疑似秘密或隐私内容时，不要公开转载，应按根目录 `SECURITY.md` 私下报告。
